# T0P0R

Настольная программа на Go (GUI — [Fyne](https://fyne.io)) для работы с метаданными файлов.

## Возможности

### 1. Даты файлов
Изменение даты создания и даты изменения. Можно выбрать один файл, несколько файлов
или папку целиком — вложенные файлы и подпапки обрабатываются рекурсивно.
Формат ввода: `дд.мм.гггг чч:мм:сс` (также принимается `гггг-мм-дд чч:мм:сс`).

Дата изменения меняется во всех системах, дата создания — только в Windows
(в Linux время рождения файла ядром не изменяется).

### 2. Автор документов Word и Excel
Изменение внутренних свойств документа — автора (создателя) и последнего редактора:

| Формат | Что изменяется |
| --- | --- |
| `.docx`, `.docm`, `.xlsx`, `.xlsm` | `dc:creator` и `cp:lastModifiedBy` в `docProps/core.xml` |
| `.doc`, `.xls` | свойства `Author` и `LastAuthor` в OLE-потоке `\x05SummaryInformation` |

Поддерживается одиночный и множественный выбор файлов, а также выбор папки
(в списке окажутся все документы поддерживаемых форматов из неё и её подпапок).

## Сборка

Требуется Go 1.23+ и системные библиотеки Fyne:

```bash
sudo apt-get install -y pkg-config libgl1-mesa-dev xorg-dev libxkbcommon-dev
make build      # обычная сборка в dist/topor
make test       # тесты
make lint       # gofmt + go vet
```

Дистрибутивы:

```bash
make deb        # dist/topor_<версия>_amd64.deb        (Debian/Ubuntu)
make appimage   # dist/T0P0R-<версия>-x86_64.AppImage  (Arch и другие дистрибутивы)
make windows    # dist/T0P0R-<версия>-windows-amd64.exe (нужен gcc-mingw-w64)
```

Те же артефакты собираются в GitHub Actions; при пуше тега `vX.Y.Z`
они прикрепляются к релизу.
