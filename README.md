# КОРОБ

Настольная программа для хранения учетных данных пользователей, генерации паролей,
печати карточек с реквизитами и экспорта информации.

- Версия: 1.0
- Автор: Сергей Владимирович Горшков
- Сайт: https://sd-on.ru
- Пожертвования: https://sd-on.ru/donate/
- Язык: Go (Golang), GUI — Fyne v2, сборка — Go Modules
- Платформы: Arch Linux, Debian, Astra Linux (x86_64, ARM64)

## Возможности

- создание, редактирование и удаление карточек пользователей;
- поля карточки: «Отдел №», «Рабочее место (АРМ) №», «Пароль для «СОБОЛЬ»»,
  «Логин О.С.», «Пароль О.С.», «Дата» с проверкой допустимых символов;
- пароли из двух частей (`!834726!` + `Numbat`), каждая часть отдельно вводится вручную
  или генерируется; генератор использует `crypto/rand` и не повторяет ранее выданные пароли;
- массовые операции: единый пароль «СОБОЛЬ» для всех карточек, уникальные пароли
  для каждой карточки, применение даты ко всем карточкам;
- оформление карточек: порядок полей перетаскиванием (Drag & Drop) или кнопками,
  размер шрифта, жирное начертание, отображение полей, общий логотип JPG
  (квадратный, правый верхний угол);
- печать 1, 4 или 6 карточек на листе A4, все или только выбранные карточки,
  разделительные линии, односторонняя печать через CUPS (`lp`), а также сохранение в PDF;
- экспорт в CSV (одна карточка — одна строка) и экспорт/импорт проекта в формате `*.7box`;
- темы оформления: светлая, темная, системная;
- раздел «О программе».

## Сборка

```bash
go build -o korob .
```

Кросс-сборка под ARM64 и упаковка выполняются целями `Makefile`:

```bash
make build       # сборка под текущую архитектуру
make test        # тесты
make build-arm64 # требуется кросс-компилятор aarch64-linux-gnu-gcc
```

### Зависимости сборки (Fyne)

- Debian / Astra Linux: `sudo apt install golang gcc libgl1-mesa-dev xorg-dev`
- Arch Linux: `sudo pacman -S go gcc mesa libxcursor libxi libxinerama libxrandr`

Готовый исполняемый файл дополнительных компонентов не требует; шрифт для печати
встроен в бинарный файл.

## Данные

Текущая база автоматически сохраняется в `~/.config/korob/korob.7box`.
Файл `*.7box` (GZIP + JSON) переносится на другой компьютер и импортируется через
меню «Файл → Импорт проекта».

## Шрифты

В каталоге `assets/fonts` находятся шрифты DejaVu (Bitstream Vera / Public Domain), встроенные в бинарный файл для формирования PDF.
